## 🛠️ Technical Arsenal

Our stack is optimized for "Survival and Scale," ensuring digital artifacts remain relevant in the evolving tech landscape.

-   **Frontend**: React 19 (Vite), Tailwind CSS (for low-latency styling).
-   **Routing**: React Router 7 (Hash-based for seamless deployment).
-   **AI Intelligence**: Google Gemini API (via `@google/genai`) for real-time technical blueprinting.
-   **Visuals**: Lucide React for iconography, custom-crafted CSS scanlines, and glassmorphism.
-   **Architecture**: Scalable SPA (Single Page Application) with a focus on modular component design.

## ⚙️ Installation & Deployment

To manifest this studio in your local environment:

1.  **Clone the Repository**
2.  **Install Dependencies**
    ```bash
    npm install
    ```
3.  **Set Environment Variables**
    Create a `.env` file and provide your Gemini API key:
    ```env
    API_KEY=your_google_gemini_api_key
    ```
4.  **Launch Local Host**
    ```bash
    npm run dev
    ```
